# 한국투자증권 AI 자동매매 봇

한국투자증권 Open API를 활용한 AI 기반 주식 자동매매 프로그램입니다.

## 주요 기능

- **다중 AI 전략**: 모멘텀, 평균회귀, 머신러닝(RandomForest) 전략을 앙상블로 결합
- **자동 리스크 관리**: 손절/익절 자동 실행, 포지션 크기 제한, 포트폴리오 비중 관리
- **실시간 자동매매**: 설정된 주기마다 시세 분석 및 자동 주문 실행
- **모의투자 지원**: 실전투자 전 모의투자 환경에서 테스트 가능

## 프로젝트 구조

```
├── main.py                  # 메인 엔트리포인트
├── config/
│   └── settings.py          # 설정 관리
├── core/
│   ├── kis_api.py           # 한국투자증권 API 클라이언트
│   ├── risk_manager.py      # 리스크 관리
│   └── trading_engine.py    # 매매 엔진
├── strategies/
│   ├── base.py              # 전략 기본 클래스
│   ├── momentum.py          # 모멘텀 전략
│   ├── mean_reversion.py    # 평균회귀 전략
│   ├── ml_strategy.py       # ML 전략
│   └── ensemble.py          # 앙상블 전략
├── utils/
│   └── logger.py            # 로깅
├── .env.example             # 환경변수 템플릿
└── requirements.txt         # 의존성
```

## 설치 및 설정

```bash
# 의존성 설치
pip install -r requirements.txt

# 환경변수 설정
cp .env.example .env
# .env 파일에 API 키, 계좌번호 등을 입력
```

## 사전 준비

1. [한국투자증권 Open API](https://apiportal.koreainvestment.com/) 포털에서 앱 키 발급
2. 모의투자 계좌 개설 (테스트용)
3. `.env` 파일에 API 키와 계좌 정보 입력

## 사용법

```bash
# 자동매매 시작 (30분 간격 리밸런싱)
python main.py

# 1회 실행 후 종료
python main.py --once

# 분석만 수행 (실제 주문 없음)
python main.py --dry-run

# 포트폴리오 상태 확인
python main.py --status
```

## 전략 설명

### 모멘텀 전략 (Momentum)
- 5일/20일/60일 이동평균선 배열 분석
- RSI(14일) 과매수/과매도 판단
- MACD 시그널 교차
- 거래량 이상 감지

### 평균회귀 전략 (Mean Reversion)
- 볼린저 밴드 이탈 감지
- 이격도 분석
- 스토캐스틱 오실레이터
- 윌리엄스 %R

### ML 전략 (Random Forest)
- 기술적 지표 기반 피처 엔지니어링
- 5일 후 수익률 예측 (매수/매도/홀드 분류)
- 피처 중요도 기반 해석

### 앙상블 전략 (기본)
- 모멘텀 30% + 평균회귀 30% + ML 40% 가중 결합
- 각 전략의 신뢰도를 반영한 종합 판단

## 리스크 관리

| 항목 | 기본값 | 설명 |
|------|--------|------|
| 최대 투자 비율 | 80% | 총 자산 대비 최대 투자 비중 |
| 개별 종목 한도 | 15% | 총 자산 대비 단일 종목 최대 비중 |
| 손절 기준 | -5% | 매입가 대비 손실률 |
| 익절 기준 | +10% | 매입가 대비 수익률 |
